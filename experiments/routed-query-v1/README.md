# Ensayo de selección de ruta y respuestas por partes

Cuatro solicitudes máximas y efectivamente intentadas; sin reintentos. Dos regresiones
guiadas sobre el documento real anterior y dos casos sintéticos nuevos. Preguntas,
criterios, código y protocolo congelados antes de ejecutar. Documento y resultados
excluidos de Git mediante inputs/ y runs/.

La segunda regresión utiliza un presupuesto de fuente completa artificialmente
bajo para ejercer la ruta del recorrido ya existente, no como configuración sugerida.
Los criterios nunca se envían al modelo; sí se envían las subpreguntas explícitas.

R1, R2 y N1 produjeron candidaturas. N2 agotó el timeout y su consumo es desconocido.
