# Reparación explícita del respaldo de C3

La afirmación original se conserva literalmente. Se añaden tres referencias:
los dos ejemplos concretos omitidos y el ejemplo de pregunta comparativa necesario
para otra parte de la misma afirmación. Ningún otro texto o localizador cambia.
El candidato pasa validación con nueve usos de citas y 4.811 bytes (antes: seis,
4.503 bytes), dentro de los límites existentes.

Jev evaluó original y derivado en llamadas separadas sin conocer el tratamiento:
original `insufficient`; derivado `supported`. Sin embargo, las distribuciones
fueron cercanas: 0,56 frente a 0,44 para el original y 0,51 frente a 0,49 para el
derivado. No son probabilidades calibradas de verdad ni validación concluyente.
Es evidencia localizada, no autorización para promoción automática.

Dos llamadas, 1.526 tokens. El original permanece como control negativo conocido;
no es un caso reservado nuevo. `verify.py` confirma exactamente los tres IDs
adicionales, integridad de originales, texto inalterado, validez estructural y
solicitudes del revisor, sin red. Las respuestas y hashes quedan en `result.json`.
Sin cambios de producto ni admisión de memoria.

La [comparación de lectura](../reading-paired-grouping-v1/README.md) usa una fuente
nueva y se evalúa por separado; este resultado no se presenta como garantía de
que cualquier agrupación preserve respaldo.
